# Genesis Outpost

Downloads for the Genesis Outpost: one small program you run inside your own network
(a laptop, a VM, Docker or Kubernetes) so that Genesis can reach databases and services
there. It only dials out over HTTPS; you open no inbound ports.

This repository holds **release binaries and install guides only**. Set up an Outpost from
**Config → Outposts** in your Genesis app, which gives you the exact commands for where you
run it.

Releases: see [Releases](../../releases). Each release lists the binaries for Linux, macOS
and Windows (amd64 and arm64) with a `SHA256SUMS` file to verify them.
